# E-Commerce Platform

A full-stack e-commerce storefront and admin dashboard built with React, TypeScript, and TanStack Query.

## Features
- Customer storefront with product catalog and shopping cart
- Secure checkout with form validation
- Admin dashboard for managing products and orders
- Role-based access control (Admin vs Shopper)

## Tech Stack
- React + TypeScript (Vite)
- React Router DOM
- TanStack Query (React Query)
- React Hook Form + Zod
- Axios

## Local Setup

1. Clone the repository
   git clone https://github.com/CherlyIC/ecommerce-app.git

2. Install dependencies
   npm install

3. Start the development server
   npm run dev

4. Open http://localhost:5173
